# myceliam Community Code of Conduct

myceliam follows the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md).

## Reporting

For incidents that are project-agnostic or impact multiple CNCF projects,
contact the [CNCF Code of Conduct Committee](https://www.cncf.io/conduct/committee/)
via <conduct@cncf.io>. For project-specific incidents, contact the myceliam
maintainers listed in [MAINTAINERS.md](MAINTAINERS.md).
